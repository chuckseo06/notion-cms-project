# Notion CMS 개인 블로그 MVP PRD

## 핵심 정보

**목적**: Notion을 CMS로 활용해 별도 관리 UI 없이 블로그 포스트를 작성·게시할 수 있는 개인 블로그 웹사이트 구축
**사용자**: 개발 관련 글을 Notion에서 작성하고 웹으로 공유하고 싶은 1인 개발자 블로거

---

## 사용자 여정

```
1. 블로그 방문자 진입
   ↓ 홈 페이지 접속

2. 홈 페이지 (포스트 목록)
   ↓ 포스트 카드 클릭

3. 포스트 상세 페이지
   ↓ 읽기 완료 후

   [태그 클릭]   → 태그 필터 페이지 (홈 페이지에 필터 적용)
   [뒤로 가기]   → 홈 페이지

4. 독자 관점 완료 (인증 불필요 — Notion에서 직접 작성)
```

**블로거(작성자) 워크플로우:**

```
1. Notion 워크스페이스에서 글 작성
   ↓ 퍼블리시 속성(Published=true) 설정

2. 다음 빌드 시 자동 반영 (ISR / 재검증)
   ↓

3. 블로그 웹사이트에 포스트 노출
```

---

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F001** | Notion 포스트 목록 조회 | Notion DB에서 Published 포스트 목록 페치·캐시 | 블로그의 핵심 콘텐츠 진입점 | 홈 페이지 |
| **F002** | 포스트 상세 렌더링 | Notion 블록을 HTML로 변환하여 가독성 있는 레이아웃으로 표시 | 실제 읽기 경험 제공 | 포스트 상세 페이지 |
| **F003** | 태그 기반 필터링 | 태그(다중 선택 속성) 클릭 시 해당 태그 포스트만 노출 | 포스트 탐색 효율화 | 홈 페이지, 포스트 상세 페이지 |
| **F004** | ISR(점진적 정적 재생성) | Notion 변경사항을 On-demand 또는 시간 기반으로 자동 반영 | 배포 없이 콘텐츠 업데이트 | 홈 페이지, 포스트 상세 페이지 |
| **F005** | OG 메타태그 생성 | 각 포스트의 제목·설명·커버 이미지로 Open Graph 태그 자동 생성 | 소셜 공유 및 SEO 필수 | 포스트 상세 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|--------------|------------|
| **F010** | Notion API 클라이언트 | `@notionhq/client` 래퍼 — 환경 변수로 인증 토큰·DB ID 관리 | 모든 데이터 소스 단일 진입점 | 홈 페이지, 포스트 상세 페이지 |
| **F011** | 404 처리 | 존재하지 않거나 미게시 포스트 접근 시 커스텀 404 페이지 반환 | 잘못된 URL 접근 방지 | 404 페이지 |
| **F012** | 전역 레이아웃 | 헤더(블로그 타이틀·네비게이션)와 푸터 공통 렌더링 | 일관된 UI 경험 제공 | 홈 페이지, 포스트 상세 페이지, 404 페이지 |

### 3. MVP 이후 기능 (제외)

- 댓글 시스템 (Giscus, Disqus 등)
- 검색 기능 (전문 검색 엔진 연동)
- 뉴스레터 구독
- 다크 모드 토글
- 포스트 조회수 카운터
- 시리즈/카테고리 계층 구조
- RSS 피드

```
    └── 기능: F002, F003, F004, F005

전역 푸터 (모든 페이지 공통)
└── 기능: F012 (저작권, 블로거 소개 1줄)
```

## 페이지별 상세 기능

### 홈 페이지

> **구현 기능:** `F001`, `F003`, `F004`, `F012` | **인증:** 불필요

| 항목 | 내용 |
|------|------|
| **역할** | 블로그 랜딩 페이지 — 전체 포스트 목록 탐색 및 태그 필터링 |
| **진입 경로** | 직접 URL 접근, 헤더 로고/타이틀 클릭, 브라우저 뒤로가기 |
| **사용자 행동** | 포스트 목록 스크롤, 태그 클릭으로 필터 적용, 포스트 카드 클릭으로 상세 이동 |
| **주요 기능** | - Notion DB에서 Published=true 포스트 목록 페치 (F001)<br>- 포스트 카드 렌더링 (제목, 날짜, 태그, 커버 이미지 썸네일, 요약)<br>- 태그 필터 UI — 태그 뱃지 클릭 시 해당 태그 포스트만 표시 (F003)<br>- ISR revalidate 설정으로 최신 포스트 자동 반영 (F004)<br>- 헤더/푸터 공통 레이아웃 렌더링 (F012)<br>- **포스트 카드 클릭** 시 포스트 상세 페이지 이동 |
| **다음 이동** | 포스트 카드 클릭 → 포스트 상세 페이지, 태그 클릭 → 동일 페이지(필터 상태 변경) |

**수용 기준 (Acceptance Criteria):**
- [ ] Notion DB의 Published=true인 포스트만 노출된다
- [ ] 포스트 카드에 제목, 작성일, 태그 목록, 요약(excerpt)이 표시된다
- [ ] 태그 뱃지 클릭 시 해당 태그를 포함한 포스트만 필터링된다
- [ ] 필터 해제(전체 보기) 버튼이 존재한다
- [ ] 포스트가 없을 때 빈 상태 메시지를 표시한다
- [ ] 페이지 최초 로드 시 ISR 캐시를 사용하고, revalidate 주기 후 갱신된다

### 포스트 상세 페이지

> **구현 기능:** `F002`, `F003`, `F004`, `F005`, `F012` | **인증:** 불필요

| 항목 | 내용 |
|------|------|
| **역할** | 개별 블로그 포스트 전문 읽기 페이지 |
| **진입 경로** | 홈 페이지 포스트 카드 클릭, 외부 링크(소셜 공유 URL) 직접 접근 |
| **사용자 행동** | 포스트 전문 읽기, 태그 클릭으로 홈 필터 이동, 코드 블록 복사 |
| **주요 기능** | - Notion Page ID 기반 블록 데이터 페치 (F002)<br>- Notion 블록 타입별 HTML 변환: 제목(H1~H3), 단락, 인용, 코드, 이미지, 구분선, 불릿/번호 목록 (F002)<br>- 코드 블록 언어 구문 강조 (Shiki) (F002)<br>- 포스트 메타정보 표시: 제목, 작성일, 태그 뱃지, 커버 이미지 (F002)<br>- 태그 뱃지 클릭 시 홈 페이지로 이동하며 해당 태그 필터 적용 (F003)<br>- ISR revalidate 설정 (F004)<br>- 동적 OG 메타태그 생성: title, description, og:image (F005)<br>- 헤더/푸터 공통 레이아웃 렌더링 (F012) |
| **다음 이동** | 태그 클릭 → 홈 페이지(태그 필터 적용), 헤더 타이틀 → 홈 페이지, 404 → 404 페이지 |

**수용 기준 (Acceptance Criteria):**
- [ ] Notion 포스트의 모든 기본 블록(텍스트, 제목, 목록, 코드, 이미지, 인용, 구분선)이 올바르게 렌더링된다
- [ ] 코드 블록에 언어 구문 강조와 복사 버튼이 있다
- [ ] 페이지 `<head>`에 포스트 제목·설명·이미지가 담긴 OG 태그가 존재한다
- [ ] Published=false이거나 존재하지 않는 slug 접근 시 404 페이지로 이동한다
- [ ] 커버 이미지가 있을 경우 히어로 이미지로 표시된다
- [ ] 태그 뱃지 클릭 시 홈 페이지의 해당 태그 필터로 이동한다

### 404 페이지

> **구현 기능:** `F011`, `F012` | **인증:** 불필요

- [ ] Next.js `not-found.tsx`를 사용한 커스텀 404 페이지가 렌더링된다
- [ ] 홈으로 이동하는 명확한 CTA 버튼이 존재한다

## 데이터 모델

### NotionPost (Notion DB 속성 매핑)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion Page ID | string (UUID) |
| slug | URL 경로용 고유 식별자 | string (Notion 속성: Slug) |
| title | 포스트 제목 | string (Notion 제목 속성) |
| publishedAt | 게시 날짜 | Date (Notion 날짜 속성) |
| tags | 태그 목록 | string[] (Notion 다중 선택) |
| excerpt | 목록 표시용 요약 | string (Notion 텍스트 속성) |
| coverImage | 커버 이미지 URL | string or null (Notion 파일/URL 속성) |
| isPublished | 게시 여부 | boolean (Notion 체크박스 속성) |

### NotionBlock (포스트 본문 블록)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 블록 고유 ID | string (UUID) |
| type | 블록 타입 | string (paragraph, heading_1~3, code, image 등) |
| content | 블록 렌더링 데이터 | object (Notion 블록 API 응답) |
| parentId | 상위 블록 ID | → NotionBlock.id or null |

### Notion DB 속성 정의 (Notion 워크스페이스 설정)

| 속성명 | Notion 타입 | 용도 |
|--------|------------|------|
| Title | 제목 | 포스트 제목 |
| Slug | 텍스트 | URL 경로 식별자 |
| Published | 체크박스 | 게시 여부 제어 |
| PublishedAt | 날짜 | 포스트 게시 날짜 |
| Tags | 다중 선택 | 태그 분류 |
| Excerpt | 텍스트 | 목록 요약 문구 |
| Cover | 파일/URL | 커버 이미지 |

### 프론트엔드 프레임워크
