# 개인 글쓰기 블로그 PRD (Product Requirements Document)

## 1. 프로젝트 개요

### 1.1 프로젝트명
**개인 글쓰기 블로그**

### 1.2 프로젝트 설명
Notion CMS를 활용하여 Notion에서 작성한 글이 자동으로 웹 블로그에 반영되는 시스템입니다. 사용자는 Notion에서만 글을 관리하면 되고, 블로그는 자동으로 최신 콘텐츠를 표시합니다.

### 1.3 CMS로 Notion을 선택한 이유
- **별도의 관리 대시보드 불필요**: Notion의 직관적인 인터페이스 활용
- **자동화**: Notion API를 통해 실시간 데이터 동기화
- **확장성**: 필요시 다양한 프로퍼티 추가 가능
- **비용 효율성**: Notion 무료 플랜으로도 충분

---

## 2. 프로젝트 목표

### 2.1 핵심 목표
1. Notion 데이터베이스와 연동된 블로그 웹사이트 구축
2. 사용자가 Notion에서 글을 작성하면 자동으로 블로그에 반영되는 시스템 구현
3. 방문자가 쉽게 글을 검색하고 필터링할 수 있는 기능 제공

### 2.2 성공 기준
- Notion API를 통한 글 목록 조회 성공
- 카테고리별, 태그별 필터링 정상 작동
- 반응형 디자인으로 모바일/태블릿/데스크톱 모두에서 정상 표시
- 글 상세 페이지 로딩 속도 3초 이내

## 3. 주요 기능

### 3.1 글 목록 조회
- **설명**: Notion 데이터베이스에서 발행된 글들의 목록을 조회합니다.
- **페이지**: `/` (홈 페이지)
- **주요 요소**:
  - 최근 글순으로 정렬
  - 글 제목, 요약(미리보기), 발행일, 카테고리 표시
  - 페이지네이션 또는 무한 스크롤 (초기: 10개씩 표시)

### 3.2 글 상세 페이지
- **설명**: 선택한 글의 전체 내용을 표시합니다.
- **페이지**: `/posts/[slug]`
- **주요 요소**:
  - 글 제목, 작성일, 수정일
  - 카테고리, 태그 표시
  - Notion 블록(텍스트, 이미지, 코드 블록 등) 렌더링
  - 이전/다음 글 네비게이션

### 3.3 카테고리별 필터링
- **설명**: 특정 카테고리의 글만 필터링하여 표시합니다.
- **페이지**: `/category/[category]`
- **주요 요소**:
  - 선택된 카테고리명 표시
  - 해당 카테고리의 글 목록
  - 카테고리 네비게이션

### 3.4 검색 기능
- **설명**: 글 제목, 태그로 검색합니다.
- **위치**: 전체 페이지 상단
- **주요 요소**:
  - 검색 입력란
  - 검색 결과 표시
  - 검색 결과 없음 메시지

### 3.5 반응형 디자인
- **설명**: 모든 화면 크기에서 최적화된 레이아웃 제공
- **대상 해상도**:
  - 모바일: 320px 이상
  - 태블릿: 768px 이상
  - 데스크톱: 1024px 이상

## 5. Notion 데이터베이스 스키마

### 5.1 데이터베이스 구조

| 필드명     | 타입         | 필수 | 설명                          |
|-----------|-------------|------|------------------------------|
| Title     | title       | ✓    | 글의 제목                     |
| Category  | select      | ✓    | 카테고리 (프론트엔드, 백엔드 등) |
| Tag       | multi_select |      | 태그 목록 (React, Next.js 등)  |
| Published | date        | ✓    | 글 발행일                     |
| Status    | select      | ✓    | 상태 (초안/발행됨)            |
| Content   | page content | ✓    | 글 본문 (Notion 블록)        |

### 5.2 카테고리 옵션 예시
- 프론트엔드
- 백엔드
- DevOps
- 개발 일지
- 기타

### 5.3 상태 옵션
- `초안` (Draft): 아직 발행하지 않은 글
- `발행됨` (Published): 블로그에 표시할 글

## 6. 화면 구성 & 라우팅

### 6.1 페이지 구조

```
/                          → 홈 (글 목록)
/posts/[slug]             → 글 상세 페이지
/category/[category]      → 카테고리별 글 목록
/about                     → 소개 페이지 (선택)
```

### 6.2 주요 페이지 명세

#### 6.2.1 홈 페이지 (`/`)
**목적**: 최근 글 목록 표시

**레이아웃**:
```
┌─────────────────────────────┐
│      Header / Navigation    │
├─────────────────────────────┤
│  검색 바                     │
├─────────────────────────────┤
│  카테고리 필터 (태그/버튼)   │
├─────────────────────────────┤
│  글 목록                     │
│ ┌──────────────────────────┐│
│ │ 글1 카드                  ││
│ │ [이미지] 제목, 날짜, 카테고리││
│ ├──────────────────────────┤│
│ │ 글2 카드                  ││
│ └──────────────────────────┘│
├─────────────────────────────┤
│  페이지네이션               │
├─────────────────────────────┤
│       Footer                │
└─────────────────────────────┘
```

**주요 컴포넌트**:
- Header: 로고, 사이트 제목, 네비게이션
- Search Bar: 키워드 검색
- Category Filter: 카테고리 선택
- Post Card: 글 정보 표시
- Pagination: 페이지 이동

#### 6.2.2 글 상세 페이지 (`/posts/[slug]`)
**목적**: 선택한 글의 전체 내용 표시

**레이아웃**:
```
┌─────────────────────────────┐
│      Header / Navigation    │
├─────────────────────────────┤
│  글 제목                     │
│  메타정보 (작성일, 카테고리) │
├─────────────────────────────┤
│  글 본문 (Notion 콘텐츠)     │
│ - 텍스트 블록                 │
│ - 이미지                     │
│ - 코드 블록 (하이라이팅)     │
│ - 인용문                     │
├─────────────────────────────┤
│  태그                        │
├─────────────────────────────┤
│  이전/다음 글 네비게이션     │
├─────────────────────────────┤
│       Footer                │
└─────────────────────────────┘
```

**주요 컴포넌트**:
- Post Header: 제목, 메타정보
- Post Content: Notion 블록 렌더러
- Tag List: 글 태그 표시
- Post Navigation: 이전/다음 글 링크

#### 6.2.3 카테고리 페이지 (`/category/[category]`)
**목적**: 특정 카테고리의 글만 필터링

**레이아웃**: 홈 페이지와 동일하되, 선택된 카테고리만 표시

## 8. 데이터 모델 & API

### 8.1 글(Post) 모델
```typescript
interface Post {
  id: string;           // Notion Page ID
  title: string;        // 글 제목
  slug: string;         // URL 슬러그
  category: string;     // 카테고리
  tags: string[];       // 태그 배열
  publishedDate: Date;  // 발행일
  modifiedDate: Date;   // 수정일
  status: 'draft' | 'published'; // 상태
  content: Block[];     // Notion 블록 배열
  excerpt: string;      // 미리보기 텍스트
}
```

### 8.2 블록(Block) 모델
```typescript
interface Block {
  id: string;
  type: 'paragraph' | 'heading1' | 'heading2' | 'heading3' | 'image' | 'code' | 'quote' | 'bulleted_list_item' | 'numbered_list_item' | 'divider';
  content: string | BlockContent;
  metadata?: {
    language?: string;     // 코드 블록의 언어
    caption?: string;      // 이미지 캡션
  };
}
```

### 8.3 주요 API 엔드포인트 (Next.js API Routes)
```
GET  /api/posts           → 글 목록 조회
GET  /api/posts/[slug]    → 글 상세 조회
GET  /api/categories      → 카테고리 목록
GET  /api/categories/[category]/posts → 카테고리별 글 목록
GET  /api/search?q=keyword → 검색 (향후)
```

## 10. 비기능 요구사항

### 10.1 성능
- **페이지 로딩 시간**: 3초 이내
- **첫 번째 콘텐츠풀 페인팅(FCP)**: 1.5초 이내
- **이미지 최적화**: WebP 형식 지원
- **캐싱 전략**:
  - ISR을 통한 정적 생성 (재생성 간격: 60초)
  - 브라우저 캐싱 활용

### 10.2 SEO
- **메타 태그 자동 생성**: 글 제목, 요약, 이미지
- **Open Graph 태그**: SNS 공유 최적화
- **구조화된 데이터**: Schema.org 마크업
- **Sitemap**: `/public/sitemap.xml` 자동 생성 (향후)

### 10.3 접근성 (Accessibility)
- **WCAG 2.1 AA 준수**
- **키보드 네비게이션 지원**
- **스크린 리더 호환성**
- **이미지 alt 텍스트 필수**
- **컬러 명도 대비 비율 4.5:1 이상**

### 10.4 보안
- **HTTPS 사용 (필수)**
- **Notion API 키 환경 변수 관리**
- **XSS 방지**: Notion 블록 렌더링 시 sanitize 처리
- **CORS 설정**: 필요시 백엔드 API 제한

### 10.5 확장성
- **컴포넌트 기반 아키텍처**
- **환경 변수를 통한 설정 관리**
- **Notion 필드 추가 시 쉽게 확장 가능한 구조**
